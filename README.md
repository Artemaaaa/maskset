# Maskset — Telegram-магазин продуктов

Стартовый проект для магазина Maskset с доставкой по территории с нумерованными домиками.

## Включено
- Каталог по категориям.
- Товары с ценой, остатком и описанием.
- Корзина и расчёт доставки: бесплатно от 2 000 ₽, иначе 100 ₽.
- Оформление с именем, телефоном, номером домика и комментарием.
- Перевод на карту и загрузка фото чека.
- Чек отправляется администратору с кнопками «Оплата подтверждена» и «Отклонить чек».
- История заказов и уведомления о статусе.
- Управление товарами командами Telegram.

## Шаг 1. Создать бота
1. В Telegram откройте `@BotFather`.
2. Отправьте `/newbot`.
3. Название: `Maskset` (или `Maskset — доставка продуктов`).
4. Выберите свободный username, заканчивающийся на `bot`, например `MasksetDeliveryBot`, если он доступен.
5. Скопируйте токен и никому его не отправляйте.

## Шаг 2. Узнать свой Telegram ID
Откройте `@userinfobot` и скопируйте числовой Telegram ID. Он нужен, чтобы бот разрешал вам админ-команды.

## Шаг 3. Установить Python
Установите Python 3.11 или новее с официального сайта python.org. На Windows при установке отметьте «Add Python to PATH».

## Шаг 4. Подготовить проект
Распакуйте архив в отдельную папку. Скопируйте `.env.example` в файл `.env`.

Заполните `.env`:
- `BOT_TOKEN` — токен BotFather.
- `ADMIN_IDS` — ваш Telegram ID, только цифры.
- `PAYMENT_DETAILS` — понятные реквизиты перевода и имя получателя.
- `SHOP_NAME=Maskset`.

Не публикуйте файл `.env` и не отправляйте токен в чаты.

## Шаг 5. Запустить на Windows
Откройте папку проекта, в адресной строке проводника напишите `cmd` и нажмите Enter. Выполните:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py bot.py
```

На macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python bot.py
```

Оставьте окно терминала открытым. Пока программа запущена, бот работает.

## Шаг 6. Добавить товары
В Telegram откройте своего бота и отправьте `/admin`.

Пример:
`/addproduct Молоко 1л|Молочные продукты|99|20|Пастеризованное молоко`

Поля разделяются вертикальной чертой `|`: название, категория, цена, количество на складе, описание.

Команды:
- `/products` — список товаров и ID.
- `/setprice ID Цена` — изменить цену.
- `/setstock ID Количество` — изменить остаток.
- `/delproduct ID` — скрыть товар.
- `/orders` — последние заказы.
- `/status ID Новый статус` — вручную изменить статус.

## Шаг 7. Протестировать
1. Добавьте несколько товаров минимум в две категории.
2. Откройте бота с другого Telegram-аккаунта.
3. Создайте заказ меньше 2 000 ₽: доставка должна быть 100 ₽.
4. Создайте тестовый заказ от 2 000 ₽: доставка должна быть бесплатной.
5. Отправьте тестовый скриншот и проверьте, что администратор получил чек и может подтвердить его.
6. Не используйте реальные платежи во время теста.

## Важные ограничения текущей версии
- Это MVP для тестов, не полностью готовая коммерческая система.
- Корзина хранится в памяти и очищается при перезапуске.
- Фото товаров пока не загружаются через админ-интерфейс; товары управляются командами.
- Остатки списываются при создании заказа. Если заказ не оплачен или отменён, остаток нужно вернуть вручную командой `/setstock`.
- Чек проверяет человек; автоматической проверки поступления денег нет.
- Для круглосуточной работы нужен постоянно работающий хостинг с постоянным хранением `shop.db`. Не используйте бесплатный хостинг, который удаляет файлы при перезапуске или засыпает.
- Перед открытием для покупателей желательно добавить постоянную корзину в БД, отмену заказа с возвратом остатков, сроки оплаты, защиту от повторных заказов, резервное копирование и журнал действий администратора.

## Постоянный хостинг
Самый простой технический вариант — небольшой VPS с Ubuntu и запуском бота как systemd-сервиса. Для этого потребуется доступ к серверу и настройка переменных окружения. Не загружайте токен в публичный репозиторий.
